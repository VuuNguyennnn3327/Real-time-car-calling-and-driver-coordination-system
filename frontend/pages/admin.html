🔑 HƯỚNG DẪN MỞ KHÓA FIREBASE (ĐỂ CÁC MÁY THẤY NHAU)

Khi triển khai lên domain hoặc dùng 2 thiết bị khác nhau, Firebase Realtime Database mặc định ở chế độ khóa (401). Để các thiết bị gửi nhận dữ liệu chung, chỉ cần 3 bước:

  1. Truy cập Firebase Console → Chọn dự án của bạn (ví dụ: navigo-app-cc7cf).
  2. Menu trái: Chọn Build → Realtime Database → Tab Rules (Quy tắc).
  3. Dán đoạn mã quy tắc bên dưới rồi nhấn Publish (Xuất bản):
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
Mọi thiết bị (điện thoại khách, tài xế, máy tính admin) cần trỏ chung vào cùng Database URL này.
