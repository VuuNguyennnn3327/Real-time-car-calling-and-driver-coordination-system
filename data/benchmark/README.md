# DATASET BENCHMARK GUIDE
Người phụ trách: **Đẹp**

Thư mục này chứa các kịch bản và tập dữ liệu lớn dùng để đo đạc hiệu năng giữa R-Tree và Naive Scan:
- Tập 1.000 điểm: Thử nghiệm tải nhẹ.
- Tập 10.000 điểm: Thử nghiệm tải trung bình (chứng minh R-Tree phản hồi < 0.5 ms).
- Tập 50.000 điểm: Thử nghiệm tải nặng (chứng minh R-Tree vượt trội hơn Naive Scan 100x - 200x).
